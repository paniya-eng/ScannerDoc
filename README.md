# Scanner Doc

اسکن چندصفحه‌ای مدارک، ابعاد دقیق (mm/cm)، فیلتر، خروجی JPG/PNG/PDF و ارسال به برنامه‌ها.

ساخت APK: فایل‌ها را در گیت‌هاب آپلود کنید، workflow به نام Build APK اجرا می‌شود و
`app-debug.apk` در بخش Artifacts قرار می‌گیرد. (فقط معماری arm64 — برای گوشی‌های ۳۲ بیتی
`armeabi-v7a` را به abiFilters در app/build.gradle.kts اضافه کنید.)
